# Skinly AI

Личный AI-помощник по уходу за кожей: рутина, напоминания, дневник, каталог косметики, анализ составов и чат с Grok. Работает на iPhone, iPad и компьютере как PWA и публикуется на GitHub Pages без сервера.

Папка `public` — это всё приложение: HTML, CSS и JavaScript без сборки.

## Публикация на GitHub Pages

1. Создайте публичный репозиторий на https://github.com/new. На бесплатном тарифе Pages работает только с публичными репозиториями.
2. Загрузите в него содержимое папки `для-github`, чтобы `index.html` лежал в корне.
3. Откройте Settings → Pages. В Source выберите Deploy from a branch, ветку `main`, папку `/ (root)` и нажмите Save.
4. Через пару минут сайт откроется по адресу `https://ИМЯ.github.io/РЕПОЗИТОРИЙ/`.

Код и сайт видны всем, но ваших данных и ключа в них нет.

## Подключение Grok

1. Создайте ключ на https://console.x.ai в разделе API Keys и пополните баланс в Billing.
2. Откройте Skinly: Профиль → AI → Ключ Grok.

Ключ хранится только на устройстве и отправляется только в xAI. Его не нужно класть в репозиторий, он не попадает в экспорт данных. На каждом устройстве ключ вводится отдельно.

## Установка на iPhone

1. Откройте адрес сайта в Safari.
2. Нажмите «Поделиться», затем «На экран “Домой”», затем «Добавить».
3. Открывайте Skinly с появившейся иконки.

## Локальный запуск

```bash
python -m http.server 3200 --directory public
```

Затем откройте http://localhost:3200.

## Ограничения

- **Напоминания работают только при открытом приложении.** Для уведомлений при закрытом приложении нужен сервер, а на GitHub Pages его нет.
- **Данные живут на устройстве и не синхронизируются.** Перенести их можно через Профиль → Экспорт данных и загрузку из файла. Делайте экспорт периодически: браузер может очистить данные сайта, если им долго не пользоваться.
- **В xAI уходят** ваши вопросы, прикреплённые фото составов и краткая сводка профиля, косметики и последних записей дневника. Фото из дневника не отправляются.
- **Skinly не ставит диагнозы и не заменяет врача.** AI может ошибаться, а реакция кожи индивидуальна.

## Структура

```
index.html, manifest.webmanifest, sw.js, icons/   каркас и PWA
css/app.css        дизайн
js/app.js          запуск и навигация
js/api.js          обращение к Grok и промпты
js/db.js, state.js хранилище и данные
js/data.js         значения по умолчанию и справочники
js/context.js      сводка для AI
js/notifications.js напоминания
js/ui.js           компоненты интерфейса
js/views/          экраны
```
